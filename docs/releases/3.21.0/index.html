Canary 3.21.0

Oliver Sauer · 11 October 2026

This release adds order queues and whole-position trailing stops, and fixes volume readings and reconnect handling.

What changed

  • Order queues: queue an approved stock or single-leg option purchase or sale, with a maximum buy price or minimum sell price.
  • IBKR Adaptive orders: choose the execution priority when previewing a stock or option limit order.
  • Trailing stops: adjust a stock trailing stop to cover the whole position as its size changes, without loosening the trail.
  • Broker data: corrected large volume readings, improved order recovery after reconnects and added read-only API settings diagnostics.

TWS and IB Gateway compatibility

These changes address TWS / IB Gateway 10.50 compatibility. Live checks passed on TWS; Gateway 10.50 still needs end-to-end validation.

Order submission requires the optional trading build and its approval checks. Standard downloads and all MCP tools remain read-only.

Install or update

Follow the installation guide or update guide. For order submission, use the trading guide.
